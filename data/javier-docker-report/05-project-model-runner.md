# 5. Project — Docker Model Runner (DMR)

← [Back to index](00-index.md)

**One line:** Led end-to-end UX for running LLMs locally through Docker Desktop — Docker's flagship "GenAI in the product" initiative — designed 0→1.

## What he did
- Designed the Model Runner experience across **Docker Desktop UI, the CLI (inference UX — push/pull), and Docker Hub**.
- Designed *and coded* the **AI model cards** on Docker Hub (`docker/model-cards`), including a new Model card layout.
- Owned the AI Model / provider-selection flow; documented the handoff (Miro + a Python model-selector repo) for continuity.
- Ran his own discovery research ("Docker Model Runner – Insights," co-authored with Francesco Corti) — Captain interviews + Slack sentiment — surfacing model discovery/import gaps that fed the UX.

## Metrics & successes
- **~2.1M total model pulls** across **~18,200 distinct models** since launch (Feb 2025).
- **~91,500 distinct users** and **~124,200 Desktop instances** have run a model.
- Monthly active model users: ~9,200 (Feb 2026) → **~10,085 peak (Apr 2026)**.
- Top models discovered through the catalog: `ai/nomic-embed-text` (~313K), Qwen2.5-Coder variants (~304K combined), `ai/gemma3` (~170K combined), `ai/llama3.2` (~94K).

## Delivery footprint
Desktop UI + CLI + Hub (three surfaces), coded model cards, handoff artifacts, and a research report — a full-stack design delivery, not just mockups.
