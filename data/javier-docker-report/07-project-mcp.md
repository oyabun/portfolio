# 7. Project — MCP Toolkit, Catalog & Marketplace

← [Back to index](00-index.md)

**One line:** Led full UX for Docker's Model Context Protocol surfaces — the MCP team built directly from his concepts — a net-new product line now serving millions of pulls.

## What he did
- Designed the **MCP Toolkit** in Docker Desktop: discovery/onboarding, tool filtering, remote MCPs, credential and client-connection flows.
- Designed the **Hub MCP Marketplace** (hub.docker.com/mcp) and **Custom MCP Server via URL** in Integrations.
- Iterated the Toolkit funnel across Desktop releases, tightening awareness → acquisition → activation → engagement.

## Metrics & successes
- **~13.1M MCP Catalog pulls** (Dec 2024 → Jul 2026) and **~10.6M MCP tool-call events**.
- **Peaked at ~10,075 weekly engaged Desktop instances / ~8,212 authenticated users.**
- **Activation ~doubled and end-to-end conversion ~2.5×** between Desktop 4.45 → 4.46 (see [Impact deltas](03-impact-deltas.md)).
- Top catalog images by pulls: `mcp/signatures` (~12.7M), `mcp/playwright` (~8.5M), `mcp/grafana` (~7.4M), `mcp/sonarqube` (~5.3M), `mcp/docker-mcp-catalog` (~5.3M).
- Top servers used from the Toolkit: dynamic-mcps (~51.9K instances), Playwright (~42.4K), Obsidian, GitHub-official, Fetch.

## Delivery footprint
Desktop Toolkit + Hub Marketplace + Integrations, with a measurable, version-over-version funnel improvement — the strongest quantified UX-impact story in the portfolio.
