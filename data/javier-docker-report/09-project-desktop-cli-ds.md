# 9. Project — Docker Desktop, CLI & the CLI Design System

← [Back to index](00-index.md)

## Docker Desktop (foundational + simplification)
- **2023–24 foundations:** Finalized Desktop UX and CLI UX (Jira ADUI-4/5), logged-out states, "Features in Development" locked state.
- **2026 simplification (with Ryan Taylor):** defining a stripped-down Desktop v1 — Workloads screen (Compose Stacks + Containers), simplified container-creation flow, display-only image security badges/vuln scores, scoped-down navigation.

## CLI Design System (DDS-CLI) — 0→1
- Built **Docker's first CLI Design System** (Notion + Figma), from a "First draft" (27 Mar 2023) to a company-wide Figma library.
- Framed explicitly as greenfield: "start Docker CLI Design System," "foundations of a CLI design system," "identify patterns and unify styles across the CLI"; created a **CLI roadmap**.
- **Now adopted org-wide** — products like **Docker Offload** use it; internally described as becoming "Docker's Organizational Standard."

## Research that seeded this work
Co-authored the **"Dockercon: CLI Research Report"** (with Rebecca Floyd, Oct 2023) — 10 attendees/captains interviewed about the CLI experience — which informed the design-system direction.

## Why it matters
The CLI Design System is a systems-level contribution: it changed how *other* teams design, multiplying his impact well beyond the surfaces he personally drew. That leverage is a principal/head-level signal.
