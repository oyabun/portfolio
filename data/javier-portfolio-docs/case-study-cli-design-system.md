# Case study — Docker CLI Design System (DDS-CLI)

← [Back to portfolio](00-README.md)

> **Created Docker's first CLI Design System — now an organization-wide standard.** Systems-level leverage: it changed how other teams design.

## Context & problem
Docker's CLI had grown organically: inconsistent patterns, styles, and terminology across commands. There was no shared system for designing CLI experiences, so every team reinvented conventions and users faced an inconsistent, hard-to-learn surface.

## My role
Creator and owner. Proposed, scoped, and built the system from scratch (Figma + Notion), and set the roadmap.

## Personas served
**P4 Sam** (newcomer, learnability) and every internal team designing CLI surfaces (an internal "developer of the design system" audience).

## Use cases (jobs-to-be-done)
- "Design a new CLI command that feels consistent with the rest of Docker." → shared patterns, components, and style guidance.
- "Reuse proven CLI patterns instead of inventing them." → company-wide Figma library.
- "Align on CLI terminology and structure." → documented conventions.

## Process
Started from research (**co-authored the DockerCon CLI Research Report**, 2023 — 10 attendees/captains interviewed), identified recurring patterns, and codified them into a first draft (27 Mar 2023), then published a company-wide Figma library and a CLI roadmap.

## Delivery
CLI Design System (Figma library + Notion documentation) · `CLI – Design System.fig` · CLI roadmap · pattern/style guidance.

## Impact
- **Adopted org-wide** — products like **Docker Offload** build on it.
- Internally described as becoming **"Docker's Organizational Standard"** for CLI.
- Multiplier effect: raises consistency and speed for every team designing CLI experiences, not just Javier's own surfaces.

## Reflection / what I'd show
This is the strongest "leverage beyond my own pixels" story — a principal/head-level signal. In a portfolio I'd show the pattern library, a before/after of an inconsistent vs. systematized command, and the list of adopting products.
