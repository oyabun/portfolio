A note on names. dagent is the Docker Agent app — create / run / pull / push / share agents — the product layer Javier designed and researched (via the Dagent UX Study), and the core of this platform. It's distinct from cagent, the open-source CLI runtime it fronts (~20.7M command events), and from Gordon, the embedded assistant. dagent's own telemetry (Sigma PREP.DAGENT, Aug 2025–Jun 2026) shows an early-stage product: 3,412 events · 96 users · 369 agents created · 2,144 runs — matching the "prototype stage" his research brief describes.
The problem

No mental model yet

Docker was building a platform to run and manage AI agents in the cloud, but the product had no established mental model: what is a session vs. a sandbox? what's a kit? how do users delegate to agents and trust the result? It started as a Vercel prototype with unvalidated core flows.

My role

Primary designer & research DRI

Defined primitives and IA, designed onboarding and the end-to-end journeys, authored the platform research plan (screener → interviews → Useberry usability tests with SUS/UMUX-Lite), facilitated the Dagent UX study, and drove a "code red" push that unblocked release.
