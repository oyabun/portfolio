Where dagent sits. dagent = the Docker Agent app (create / run / pull / push / share agents + marketplace). It's distinct from cagent, the open-source CLI runtime it fronts (~20.7M command events), and from Gordon, the embedded assistant. dagent is the prototype that matured into the Agentic Platform / AI Cloud.

The problem

Make agents shareable & runnable

Developers needed a way to define an agent once, run it, and share it — without wrangling code, dependencies, and orchestration. The app had to make the agent lifecycle (create → run → push/pull) feel as natural as working with container images, while validating an unproven mental model.

My role

Designer & researcher

Designed the agent-lifecycle flows and the marketplace/fleet — and ran the research myself: facilitated the Dagent UX Study (~11 moderated think-aloud sessions, Oct 2025) and built a Qualtrics feedback form that accepted agents by URL or .yaml upload.

Jobs to be done

Use cases designed

  • Create an agent and configure its models/tools
  • Run an agent and inspect the result
  • Pull a community agent from the marketplace
  • Push / share an agent to the fleet
  • Import an existing agent by URL or .yaml
Delivery & research

What shipped

Agent create/run/edit/import-export flows · agent marketplace (fleet) · the Dagent UX Study (plan, facilitation, synthesis) · a Qualtrics feedback instrument. This work fed directly into the Agentic Platform's primitives.
