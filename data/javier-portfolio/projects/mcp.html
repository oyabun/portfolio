The problem

Fragmented, unsafe setup

Developers had no trusted, discoverable way to find MCP servers or safely connect them to clients like Cursor, Claude, and Gordon. Setup meant cloning repos, wrangling secrets, and running tools with full host access.

My role

Design lead, all surfaces

Designed the Desktop Toolkit (discovery, add-server, credentials, client connection) and the Hub Marketplace, plus Custom MCP Server via URL — and owned the activation funnel, iterating it version over version.

Impact, measured

Activation ~doubled: Desktop 4.45 → 4.46

Conversion at each funnel stage, as % of aware users. Same surface, consecutive releases — the cleanest "design moved the metric" story.
