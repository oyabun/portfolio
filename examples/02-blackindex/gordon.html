S-01 — Context

A true 0→1 bet.

Docker needed an AI assistant meeting developers where they work — Desktop + CLI. No separate chat tool, and no unsafe agent actions on their machine.

No established pattern. No existing users.

  • Surfaces Docker Desktop · CLI
  • Constraint never leave the tools devs already run
  • Constraint an agent must never act destructively without an okay
S-02 — Role

Design lead, end to end.

Owned the surface from first sketch to GA pricing: how the agent is summoned, how it is trusted, how it is billed, and how its failures come back to the team.

  • Interaction model
  • Onboarding
  • Safety / permission UX
  • Billing & GA flows
  • Support integration
  • Feedback research pipeline
S-03 — Jobs-to-be-done

“Ask about my containers/images/compose without leaving Docker.”

→ Gordon in global search + Containers / Images / Volumes tabs

“Let the agent act — but never do something destructive without my okay.”

→ Danger classification (cautious / safer tiers) · allow/deny dialog · CLI hook
The safety pattern became the reference for other agent dialogs across Docker.

“Understand what Gordon costs and which plan I need.”

→ Budget / token views · plan mode · pricing

“Get started without reading docs.”

→ Onboarding + login nudge

“Tell Docker when Gordon gets it wrong.”

→ In-product Qualtrics feedback → permalink → Slack routing

Authored the continuous research plan and stood up the feedback pipeline, then iterated free/blocked states, JIT nudges, and permission tiers across releases — shipping each step of the ladder to GA.
