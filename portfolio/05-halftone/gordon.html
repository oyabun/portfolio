Study Sheet № 01 · Docker · 2024–2026

Gordon

From a 69-user prototype to ~119,700 monthly active users.

藍

Role Design lead, end-to-end Dates 2024–2026 Personas Ana — AI-curious dev · Sam — newcomer · Marco — safety & governance · Dana — plans & pricing

01壱

Context

Docker needed an AI assistant that meets developers where they already work — Desktop and CLI — not a separate chat tool, and never an agent taking unsafe actions on their machine. A true 0→1 bet: no established pattern, no existing users.

02弐

Role

  • Interaction model
  • Onboarding
  • Safety / permission UX
  • Billing & GA flows
  • Support integration
  • Feedback research pipeline
03参

Jobs-to-be-done

The developer asksThe design answer
Ask about my containers/images/compose without leaving Docker. Gordon in global search + the Containers / Images / Volumes tabs.
Let the agent act — but never do something destructive without my okay. Danger classification (cautious / safer tiers), the allow/deny dialog, a CLI hook. ⁎ The safety pattern became the reference for other agent dialogs across Docker.
Understand what Gordon costs and which plan I need. Budget / token views, plan mode, pricing.
Get started without reading docs. Onboarding + login nudge.
Tell Docker when Gordon gets it wrong. In-product Qualtrics feedback → permalink → Slack routing.
04肆

Process

Authored the continuous research plan and stood up the feedback pipeline. Iterated free/blocked states, JIT nudges and permission tiers across releases — shipping V2 GA + pricing (Apr 2026), GA with Desktop 4.74 (May 2026), and again in 4.80 (Jul 2026).
